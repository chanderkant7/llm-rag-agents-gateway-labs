# Course 1: Foundations

## Overview

This course covers the foundational concepts of Large Language Models (LLMs), Langchain, and LiteLLM. It's designed for beginners to understand core AI/ML concepts before diving into advanced RAG and Agentic AI implementations.

## Learning Objectives

- Understand how LLMs work
- Set up Langchain environment
- Learn LiteLLM basics and provider integration
- Build simple LLM applications
- Understand prompting and model behavior

## Getting Started

1. Ensure virtual environment is activated:
```bash
source .venv/bin/activate  # Linux/macOS
# or
.venv\Scripts\activate     # Windows
```

2. Install dependencies:
```bash
uv pip install -r ../requirements.txt
```

3. Configure API keys in `.env` file at project root

4. Start with the introductory notebooks and follow sequentially

## Prerequisites

- Python 3.8+
- Basic Python knowledge
- API key for at least one LiteLLM provider (OpenAI recommended)

## What You'll Learn

- **LLM Fundamentals**: Transformers, tokens, context windows
- **Langchain Basics**: Chains, prompts, memory, callbacks
- **LiteLLM Setup**: Provider integration, multi-model support
- **Simple Applications**: Chatbots, Q&A systems, text generation

## Next Steps

After completing Course 1, proceed to **Course 2: RAG Basics** to learn about Retrieval-Augmented Generation.
